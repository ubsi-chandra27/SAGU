# MILESTONES.md

Milestone proyek SAGU.

## M0 - Dokumentasi Proyek

Status: direncanakan selesai pada fase awal.

Kriteria selesai:

- Semua dokumen utama tersedia.
- MVP dan non-scope jelas.
- Role dan workflow terdokumentasi.
- Struktur database awal tersedia.

## M1 - Fondasi Sistem

Kriteria selesai:

- Aplikasi dapat login dan logout.
- Role Admin, Guru, Wali Kelas, Siswa, dan Orang Tua tersedia.
- Pengaturan sekolah, tahun ajaran, dan semester dapat dikelola.
- Proteksi route dasar berjalan.

## M2 - Data Master

Kriteria selesai:

- Admin dapat mengelola guru.
- Admin dapat mengelola siswa.
- Admin dapat mengelola kelas, rombel, dan mata pelajaran.
- Admin dapat mengatur penugasan guru dan wali kelas.

## M3 - Absensi dan Agenda

Kriteria selesai:

- Guru dapat mencatat absensi.
- Guru dapat membuat agenda mengajar.
- Wali kelas dapat memantau rekap absensi rombel.
- Siswa dan orang tua dapat melihat ringkasan absensi.

## M4 - Penilaian dan Leger

Kriteria selesai:

- Guru dapat menginput nilai.
- Wali kelas dapat melihat leger rombel.
- Admin dapat memantau rekap nilai.
- Siswa dan orang tua dapat melihat nilai yang sudah dipublikasikan.

## M5 - Laporan MVP

Kriteria selesai:

- Laporan data guru tersedia.
- Laporan data siswa tersedia.
- Laporan absensi tersedia.
- Laporan leger tersedia.
- Ekspor laporan tersedia sesuai keputusan teknis.

## M6 - Beta Internal

Kriteria selesai:

- Modul MVP diuji dengan data contoh.
- Bug kritis tertangani.
- Dokumentasi deployment tersedia.
- Sekolah uji coba dapat memakai alur utama.
